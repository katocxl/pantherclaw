### G0 — M29 — Model connections and token budgets: the agent reaches its model through the gateway, caps in tokens, a fake model for zero-token tests — 2026-11-04

This brief is written before implementation (G0). It lists planned scope; delivery status is tracked by the M29 pull requests and, at the end of the milestone, in the exit status. The design was written from a reading of `main` at 44f281bb and the M28 exit. The founder approved the plan as planned on 2026-11-04 (Q1–Q5) and answered three further questions the same day (FQ-A, FQ-B, FQ-C). The streams build in parallel and land as one exit pull request.

**Purpose:** a coding agent run in `pclaw sandbox run` could not reach its model, and nothing measured or capped the tokens agents spend. Five things blocked it: the edge refuses every host without a mapped connection and no package existed for a model provider; the edge strips the agent's key; `pclaw sandbox run` has no `--env`; the edge and the gateway's HTTP face cap bodies at 64 KiB; and neither streams, with a 2-minute timeout. Budgets count money and action counts only. M29 adds model connections: the gateway holds the key, decides each call like any other action, scans the prompt for secrets, streams the answer, and meters tokens against caps on grants, guardrail envelopes and runs. A fake model lets the range, CI and customers test every control without spending a token. M25's campaign model route (HR-613..HR-615) is unchanged.

**Scope:**
- **Model connections** (F980, F981). Connection kind `model`; packages `pc.anthropic` (Messages, token counting, models) and `pc.openai` (Chat Completions, Responses, models; OpenAI-compatible servers and Azure OpenAI's v1 API); the key held and placed by the gateway; the checked prompt path; 16 MiB, streaming, 10 minutes; the whole-prompt secret scan; provider-side tools refused unless allowed; no capture; refusals in the provider's error shape.
- **Tokens** (F982–F984, F986–F988). `max_tokens` rules on grants and guardrail envelopes, a run cap, reserve by estimate and settle by reported usage, `TOKEN_BUDGET_EXHAUSTED`; `pclaw sandbox run --max-tokens` and `--env`; token lines in the views; usage rows; estimates and the monthly token report on Team.
- **Fake model** (F985). `pantherclaw-sim model`, RT-190..RT-197, the end-to-end tests.
- **Console** (F989, and the console parts of F987, F988). Private, after the API is on `main`.

Editions: model connections, token caps, the run cap, `--env`, the fake model and every token view on every edition; estimates and the monthly token report on Team.

**Out of scope:** model routing or choosing between providers; caching or replaying model replies; Bedrock and Vertex native APIs; a shipped price list; capturing prompts or replies on model connections; Azure OpenAI's deployment-path API; changing M25's campaign model route; mapping token caps into the M28 threat map.

**Founder decisions (2026-11-04, recorded, not re-asked):**
- **Q1 A.** Model connections through the gateway: the gateway holds the provider key as a sealed credential and places it; the agent never holds a key (HR-213 stays); a key the agent sends is still stripped.
- **Q2 A.** Caps counted in tokens, with an optional customer-set price per connection for an estimate only, marked "estimate"; no shipped price list.
- **Q3 A.** A secret in a prompt is still held for a person (`SECRET_IN_PAYLOAD`).
- **Q4 A.** No prompt or reply capture on model connections; metadata and token counts only.
- **Q5 A.** A new coordinator after M28; the streams build once M28 is on `main`.
- **Editions.** As above.
- **FQ-A, check and forward.** The gateway strictly parses the prompt JSON, decides on its metadata and a body fingerprint, scans every part for secrets and forwards exactly that checked JSON; approvals and receipts bind the fingerprint; it adds the connection's max tokens when absent. A written exception to HR-075 for model connections only (HR-691).
- **FQ-B, refuse unless allowed.** Provider-side tools (web fetch and search, code execution, remote MCP servers, background mode, unknown typed tools) are refused unless an admin allows the named type on that model connection (HR-696).
- **FQ-C, stop and show.** A held call from a sandboxed agent stops and is shown: the edge gives each request a new action id, so it cannot be resumed after approval, as for every connection today. Resuming through the sandbox is a follow-up.
