### G0 — M26 — Enterprise identity: IdP access, MCP client authorization, SCIM, SAML and SaaS agent discovery — 2026-11-01

This brief is written before implementation (G0). It lists planned scope; delivery status is tracked by the M26 pull requests and, at the end of the milestone, in the exit status section. The design was written on `main` at baaa118d and the brief on 72993c28. M25, M26 and M27 build in parallel as wave 2 (W1) and land in migration order (W2). The founder answered the wave 2 rules on 2026-10-31 (H4) and the open questions on 2026-11-01 (H7, H8).

**Purpose:** enterprises want agent access granted in their identity provider and enforced per task by PantherClaw. Standard MCP clients expect the MCP 2026-07-28 authorization flow. IT wants SCIM and SAML before it signs. And most enterprise agents are built in SaaS tools that PantherClaw does not mediate, so they do not appear at all. M26 makes PantherClaw the per-task layer behind the customer's IdP, adds an opt-in route for standard MCP clients, adds SCIM and SAML, and lists agents from Copilot Studio and ChatGPT Enterprise. A reading of the code found: nothing tagged M26 exists; `oauthhttp.HandleGrant` is the jwt-bearer entry; ID-JAG is still an IETF draft, so it sits behind an adapter; organization identity providers exist only for sign-in (ADR-0039); no real captures of the SaaS sources exist yet.

*IdP access* (TB4, TB8; D400–D403).
- **Spoofing (T-266):** a forged assertion, or an issuer one person added. Answered by: exact mapping (HR-621), a two-person protected issuer entry (HR-622) and a labelled simulator (HR-627).
- **Elevation (T-267):** an assertion creates or widens authority. Answered by: use or narrow an existing grant, or `NO_GRANT` (HR-620).
- **Tampering (T-268):** a token is reused at another server, or keeps working after a revoke. Answered by: 5 minutes, one server, a full policy check on every call (HR-624) and a revoked grant stopping the next call (HR-626).
- **Spoofing (T-269):** a bearer client passes as an attested workload. Answered by: an opt-in route and an allow-listed client URL (HR-623), and a weaker proof that policy can refuse (HR-625).

*Provisioning* (TB8, TB12; D405, D406).
- **Elevation (T-270):** a stolen SCIM token or a group mapping reaches admin, or deprovisioning strands an organization. Answered by: hash only (HR-629), non-admin roles (HR-630), a protected change (HR-631) and the last-admin refusal (HR-632).
- **Spoofing (T-271):** a forged or replayed SAML assertion. Answered by: signed assertions, audience and a replay cache (HR-633), and routes under the extension prefixes (HR-634).

*SaaS discovery* (TB8; D407).
- **Information disclosure (T-272):** an importer collects conversations. Answered by: metadata only (HR-635).
- **Repudiation (T-273):** a source not read looks empty, a synthetic fixture looks like a real capture, or an imported agent gains authority. Answered by: "not scanned" (HR-637), the SYNTHETIC label (HR-636), and OBSERVE_ONLY with no key path (HR-638).

**Design decisions:**

*S26a — IdP access ([ADR-0048](../adr/0048-idp-assertions-and-mcp-client-authorization.md))*

1. **D400** (F910–F912, HR-620, HR-621, H8). `internal/idaccess/{domain,app,ports}`; port `AssertionVerifier`, adapter `adapters/idjag` naming the draft revision. It enters through `oauthhttp.HandleGrant` jwt-bearer. `iss+sub` maps to `pc.users`; `client_id` maps to an enrolled agent by a pinned binding (HR-140). Run principal source `id_jag`. The assertion's scope intersects the grant. No existing grant: refused `NO_GRANT`.
2. **D401** (F913, HR-622). `pc.org_assertion_issuers`, a two-person protected change (HR-481..484), HTTPS discovery through the egress guard, pinned audience. `IdpAccess()` Team. ADR-0048 amends ADR-0039 point 2 and explains why this isn't ADR-0018's rejected token-exchange service.
3. **D402** (F914–F916, HR-623, HR-624, HR-625, H8). Gateway face `internal/gateway/mcpauth`, off by default per organization. MCP 2026-07-28: RFC 9728 metadata, issuer check, RFC 8707 audience, CIMD. A client URL is allow-listed by the organization to one enrolled agent. Authorization server endpoints in `oauthhttp`. Token `pap-mcp+jwt`, 5 minutes, `aud` one gateway server. The gateway forwards it and the Authority re-verifies it (HR-021). Policy attribute `workload.proof == "bearer"`; it never satisfies an attestation requirement. PAP/1 routes are unchanged.
4. **D403** (F917, HR-626, HR-627). `internal/sim/okta` plus `*_cli.go`, with the SIMULATED mark. Exit: an agent uses an existing grant through the test IdP, per task; no grant is refused; a revoked grant stops the next call. The real tenant check stays pending (F801). Entra conditional-access facts are out.

*S26b — provisioning*

5. **D405** (F918–F920, F923, HR-629, HR-633, HR-634, H7). Core tables `pc.groups`, `pc.group_members`, `pc.group_role_mappings`, `pc.scim_tokens` (hash only), `pc.saml_connections`; ports `internal/provisioning/ports`; `extension.Deps` gains them, `AuditRecorder` takes `scim.` and `saml.`, sets compose. Private `enterprise/` package and `cmd/pantherclaw-server-ee` with no billing or console. Routes `/v1/ext/scim/v2/*` and `/app/ext/saml/*` (HR-341 unchanged). SP-initiated SAML; signed assertions, audience, replay cache. S26b proposes the SAML library and the coordinator decides.
6. **D406** (F921, F922, HR-630, HR-631, HR-632). Deprovision ends sessions and API keys and respects HR-484: the last admin is refused, as an owned failure. A group maps only to non-admin roles: Org Admin and Security Admin bindings stay in PantherClaw (R-08). A mapping change is a protected change. `SCIM()`, `SAML()` Enterprise.

*S26c — SaaS discovery*

7. **D407** (F924–F929, HR-635..638). `internal/saasdiscovery`, sources `copilot_studio` and `chatgpt_enterprise`.
    - Pure parsers, `pclaw discover import --source <s> --file <f>`, and a collector through a gateway lease like `StartOrgScan`, tested on `internal/sim/<vendor>`.
    - Metadata only, never conversations (H3, F789).
    - Fixtures are labelled SYNTHETIC: no real captures exist yet.
    - It reports "not scanned", never "none found".
    - Agents land DISCOVERED, OBSERVE_ONLY, with an `external` mark and no key path. Claiming sets an owner only.
    - A queue source. `SaaSDiscovery()` Business.
